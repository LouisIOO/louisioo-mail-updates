# LouisiOO Mail — mises à jour

Ce dépôt public contient uniquement les installateurs et métadonnées nécessaires aux mises à jour automatiques de LouisiOO Mail.

Il ne contient aucun code source, e-mail, compte, jeton, mot de passe ni secret. Les versions publiées ici restent des versions DEV 0.x tant que la production 1.0 n’a pas été validée explicitement.
